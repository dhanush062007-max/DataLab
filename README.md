# DataLab

DataLab is a complete Data Science web platform that allows users to seamlessly move from raw data to real insights. 
It supports data collection, cleaning, exploratory data analysis (EDA), visualization, statistical testing, machine learning, and automated reporting.

## Overview

The platform uses a modern, stateless architecture to ensure scalability:
- **Frontend**: Next.js (App Router), React, Tailwind CSS, shadcn/ui.
- **Backend**: FastAPI (Python 3.11+).
- **Data Science**: Pandas, Scikit-learn, SciPy.
- **Database & Auth**: Supabase.
- **Jobs & Cache**: Redis + Celery/RQ.
